# Student Automation Scripts

This directory houses cross-platform PowerShell and Bash automation scripts for reproducible student workflows.

## Scripts
- `build-images.ps1`: Build and tag frontend & backend container images locally.
- `deploy-minikube.ps1`: Streamlines applying manifests or Helm charts to local Minikube.
- `cleanup-minikube.ps1`: Cleans up local learning resources to reclaim workstation memory.
- `cleanup-aws.ps1`: Teardown helper for AWS resources to prevent unintended cloud charges.
