# Docker Architecture & Containerization Module

This directory contains containerization documentation, build notes, and Docker Compose configurations developed in **Milestone 2**.

## Contents & Objectives
- **Multi-stage Dockerfiles**: Frontend Nginx alpine image & Backend Node alpine image.
- **Docker Compose**: Orchestrates frontend, backend, and health monitoring on local bridge network.
- **Security**: Non-root execution, minimal attack surface, no embedded secrets.
